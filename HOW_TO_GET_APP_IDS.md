1️⃣ الفرق بين Testnet و Mainnet
════════════════════════════════════════════════════════════════════════════

┌─────────────────┬──────────────────────────┬──────────────────────────┐
│ الخاصية          │ Testnet (تجريبي)        │ Mainnet (حقيقي)         │
├─────────────────┼──────────────────────────┼──────────────────────────┤
│ الموقع          │ testnet.minepi.com      │ minepi.com               │
│ الغرض           │ الاختبار والتطوير       │ الإنتاج والمستخدمين     │
│ الرسائل         │ رسائل اختبار (لا قيمة) │ رسائل حقيقية (قيمة)     │

│ البيانات        │ منفصلة                  │ منفصلة                   │
│ حالة التطوير    │ للمطورين                │ للمستخدمين النهائيين   │
└─────────────────┴──────────────────────────┴──────────────────────────┘

الخلاصة:
- استخدم Testnet أثناء التطوير والاختبار
- استخدم Mainnet بعد إطلاق التطبيق للجمهور

2️⃣ الحصول على App ID من Testnet (للاختبار)
════════════════════════════════════════════════════════════════════════════

الخطوة 1: الذهاب إلى موقع Testnet Developer
────────────────────────────────────────────────────────────────────────────
اذهب إلى: https://testnet.minepi.com

ستظهر لك الصفحة الرئيسية لـ Pi Network Testnet

الخطوة 2: تسجيل الدخول أو الاشتراك
────────────────────────────────────────────────────────────────────────────
- اضغط على "Sign In" أو "Join" أعلى اليمين
- استخدم حسابك Pi Network
- أو أنشئ حساب جديد

الخطوة 3: الذهاب إلى قسم Developer
────────────────────────────────────────────────────────────────────────────
بعد تسجيل الدخول:
1. اضغط على اسمك أعلى اليمين → قائمة
2. ستجد خيار "Developer" أو "Developers"
3. اضغط عليه

الخطوة 4: إنشاء تطبيق جديد
────────────────────────────────────────────────────────────────────────────
1. اضغط على "Create App" أو "New Application"
2. ملء النموذج:
   
   التطبيق:
   ├─ اسم التطبيق: "P314 Chat Bot Testnet"
   ├─ الوصف: "Chat bot application for testing"
   ├─ الموقع (URL): https://localhost:3000 (للتطوير)
   ├─ النوع: "Web App" أو "Web Application"
   └─ الإعدادات: اقبل الافتراضية

3. اضغط على "Create" أو "Submit"

الخطوة 5: نسخ App ID
────────────────────────────────────────────────────────────────────────────
بعد الإنشاء ستظهر:

┌──────────────────────────────────┐
│ Application Details              │
├──────────────────────────────────┤
│ App Name: P314 Chat Bot Testnet  │
│ App ID: p314-aa57cb98de8ff227    │  ← انسخ هذا
│ Status: Active                   │
│ Created: 2024-01-15              │
└──────────────────────────────────┘

1. اضغط على App ID لتحديده
2. انسخه (Ctrl+C أو Cmd+C)
3. احفظه في مكان آمن

معرف Testnet = p314-aa57cb98de8ff227

الخطوة 6: (اختياري) احصل على API Key
────────────────────────────────────────────────────────────────────────────
في نفس الصفحة:
1. ستجد "API Key" أو "Secret Key"
2. اضغط على "Show" أو "Copy"
3. انسخه بأمان (لا تشاركه مع أحد)

3️⃣ الحصول على App ID من Mainnet (للإنتاج)
════════════════════════════════════════════════════════════════════════════

العملية تماماً مثل Testnet، لكن على:

الخطوة 1: اذهب إلى Mainnet Developer
────────────────────────────────────────────────────────────────────────────
اذهب إلى: https://minepi.com

(بدلاً من testnet.minepi.com)

الخطوة 2-3: تسجيل الدخول والذهاب إلى Developer
────────────────────────────────────────────────────────────────────────────
نفس الخطوات السابقة تماماً

الخطوة 4: إنشاء تطبيق جديد
────────────────────────────────────────────────────────────────────────────
لكن هذه المرة:

النموذج:
├─ اسم التطبيق: "P314 Chat Bot"
├─ الوصف: "Chat bot application"
├─ الموقع (URL): https://your-domain.vercel.app (المجال الحقيقي)
├─ النوع: "Web App"
└─ الخصوصية: اقرأ وسجل الموافقة

⚠️ ملاحظة مهمة:
- يجب أن يكون الموقع (URL) حقيقياً وله نطاق فعلي
- لا تستخدم localhost
- استخدم نطاقك على Vercel أو نطاقك الخاص

الخطوة 5: نسخ App ID من Mainnet
────────────────────────────────────────────────────────────────────────────

معرف Mainnet = (سيكون مختلف عن Testnet)
مثال: p314-bb67fc09ad8gg338

⚠️ تذكر:
- معرف Testnet مختلف عن Mainnet
- تحتاج إلى معرفين منفصلين

4️⃣ أين تضع كل معرف؟
════════════════════════════════════════════════════════════════════════════

في Vercel Environment Variables:

للـ PREVIEW (Testnet - للاختبار):
────────────────────────────────────────────────────────────────────────────
إعداد: Preview Environment
متغيرات:

  NEXT_PUBLIC_APP_ID_SANDBOX=p314-aa57cb98de8ff227
  NEXT_PUBLIC_APP_ID_TESTNET=p314-aa57cb98de8ff227
  PI_APP_ID=p314-aa57cb98de8ff227
  PI_API_KEY=your_api_key_here_testnet
  NEXT_PUBLIC_BACKEND_URL_SANDBOX=https://testnet-api.minepi.com
  MONGODB_URI_SANDBOX=mongodb+srv://...testnet...
  MONGODB_DB_NAME=p314-testnet

للـ PRODUCTION (Mainnet - للحقيقي):
────────────────────────────────────────────────────────────────────────────
إعداد: Production Environment
متغيرات:

  NEXT_PUBLIC_APP_ID_MAINNET=p314-bb67fc09ad8gg338
  PI_APP_ID=p314-bb67fc09ad8gg338
  PI_API_KEY=your_api_key_here_mainnet
  NEXT_PUBLIC_BACKEND_URL_MAINNET=https://api.minepi.com
  MONGODB_URI_MAINNET=mongodb+srv://...mainnet...
  MONGODB_DB_NAME=p314-mainnet

5️⃣ اختبار المعرفات
════════════════════════════════════════════════════════════════════════════

بعد إضافة المعرفات في Vercel:

الخطوة 1: اختبر محلياً
────────────────────────────────────────────────────────────────────────────
npm run dev
# افتح http://localhost:3000
# اختر Testnet
# حاول تسجيل الدخول

الخطوة 2: تحقق من console للأخطاء
────────────────────────────────────────────────────────────────────────────
في متصفح:
1. اضغط F12 لفتح Developer Tools
2. اذهب إلى "Console" tab
3. ابحث عن أي رسائل خطأ تتعلق بـ App ID

الخطوة 3: اختبر على Vercel
────────────────────────────────────────────────────────────────────────────
1. ادفع التغييرات: git push origin main
2. انتظر deployment على Vercel
3. افتح https://your-project.vercel.app
4. اختر Mainnet
5. حاول تسجيل الدخول

الخطوة 4: تحقق من الأخطاء الشائعة
────────────────────────────────────────────────────────────────────────────
رسالة الخطأ         │ السبب                      │ الحل
────────────────────┼─────────────────────────────┼───────────────────
"Invalid App ID"    │ معرف خاطئ                 │ تحقق من النسخ
"App not found"     │ معرف من بيئة أخرى         │ استخدم الصحيح
"Invalid URL"       │ الموقع غير متطابق         │ حدّث في Developer
"Unauthorized"      │ API Key خاطئ              │ تحقق من المفتاح

6️⃣ استكشاف الأخطاء
════════════════════════════════════════════════════════════════════════════

المشكلة: لا أستطيع الوصول إلى Developer
════════════════════════════════════════════════════════════════════════════
الحل:
1. تأكد من أن حسابك مفعّل في Pi Network
2. تسجيل الدخول قد يأخذ وقتاً (انتظر دقيقتين)
3. جرّب متصفح مختلف
4. امسح ذاكرة التخزين المؤقت (Ctrl+Shift+Delete)

المشكلة: لا أرى زر "Create App"
════════════════════════════════════════════════════════════════════════════
الحل:
1. تأكد من تسجيل الدخول (تحقق من أعلى اليمين)
2. اذهب مباشرة إلى: https://testnet.minepi.com/admin/app
3. أو https://minepi.com/admin/app
4. قد تحتاج إلى تفعيل حسابك كمطور

المشكلة: معرفي لا يعمل
════════════════════════════════════════════════════════════════════════════
الحل:
1. تحقق من عدم وجود مسافات في البداية/النهاية
2. تأكد من صحة النسخ (مقارنة character by character)
3. تأكد من استخدام المعرف في البيئة الصحيحة
4. جرّب حذف و إعادة إنشاء التطبيق

المشكلة: لا أستطيع تسجيل الدخول على الموقع
════════════════════════════════════════════════════════════════════════════
الحل:
1. تحقق من شهادة Pi Network:
   - https://testnet.minepi.com/hello (للـ Testnet)
   - https://minepi.com/hello (للـ Mainnet)
2. استخدم متصفح Edge أو Chrome
3. تأكد من تفعيل JavaScript
4. جرّب Incognito Mode
